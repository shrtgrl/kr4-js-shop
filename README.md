# Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

## Описание

**HeartBeat** — учебный интернет-магазин виниловых пластинок. В рамках КР №4 в него добавляется интерактивность на чистом JavaScript (без React, Vue и сторонних библиотек).

## Основа проекта

Проект `kr4-js-shop` создан как отдельный репозиторий на основе адаптивной версии интернет-магазина из **контрольной работы №3** (`kr3-responsive-shop`).

Из КР №3 перенесены:

- 5 страниц: главная, каталог, карточка товара, заявка, контакты;
- адаптивная вёрстка (Mobile First, `responsive.css`);
- доступность: skip-link, видимый фокус, `aria-*`, модальное окно на `<dialog>`;
- бургер-меню и сворачиваемый фильтр каталога.

Тематика изменена: вместо учебного магазина — магазин виниловых пластинок HeartBeat. Фотографии заменены на SVG-заглушку `images/placeholder-record.svg`.

## Принцип безопасного вывода данных

Для вывода данных используется `textContent`, а не `innerHTML`.

`innerHTML` разбирает строку как HTML-разметку. Если строка пришла от пользователя (из формы, `localStorage` или API), в ней может оказаться, например, `<img src=x onerror=alert(1)>` — браузер создаст элемент и выполнит чужой код (XSS-атака).

`textContent` всегда вставляет строку как обычный текст, поэтому любые теги просто отображаются символами. Этот опыт показан в `js/main.js` (этап 13) и оставлен закомментированным.

## Почему `defer` и порядок скриптов

```html
<!-- catalog.html -->
<script src="js/data.js" defer></script>
<script src="js/catalog.js" defer></script>
<script src="js/main.js" defer></script>
```

- `defer` — скрипт загружается параллельно с HTML и выполняется после разбора страницы, поэтому `querySelector` находит элементы;
- скрипты с `defer` выполняются в порядке подключения: сначала `data.js` создаёт данные, затем `catalog.js` и `validation.js` их используют;
- обычные (не модульные) скрипты делят глобальную область видимости, поэтому `catalog.js` и `validation.js` видят массив `products` из `data.js`.

## Как запустить

1. Открыть папку проекта в VS Code.
2. Запустить `index.html` через Live Server.
3. Открыть `catalog.html`: проверить поиск, фильтр по жанру, сортировку и пустое состояние.
4. Открыть `order.html`: отправить пустую форму, проверить ошибки, затем отправить корректные данные.
5. Открыть DevTools → Console и убедиться, что ошибок нет.
